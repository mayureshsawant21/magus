    Presentation Studio

    This site runs on GitHub Pages, so your edits are saved straight to the GitHub repository. Connect once with an access token.

    1. Create a fine-grained token on GitHub ↗
    2. Under Repository access, choose Only select repositories and pick this repository.
    3. Under Permissions → Repository, set Contents to Read and write. Optionally set Actions to Read to see when the live site has updated.
    4. Generate the token, then paste it below.
